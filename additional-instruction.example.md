# Post-run skill usage audit

Please, be honest.

After the security assessment is complete, add a section titled **Loaded SKILL audit** to the final report.

For every SKILL that was actually loaded during the run, report:

- the exact SKILL name;
- the agent that loaded it;
- why it was loaded;
- a usefulness rating of High, Medium, or Low;
- a one-sentence justification for that rating.

Only report information that is directly observable from the run. Do not infer or invent SKILL usage, agent attribution, or usefulness evidence. If any requested field is unavailable, mark it as `Not observable` and briefly explain the limitation.
